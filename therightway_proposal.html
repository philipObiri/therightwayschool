Section 02

Understanding Your Institution

The RightWay Centre of Learning is a private school in Trinidad & Tobago offering Early Childhood Education, Primary School, and SEA preparation. As the school grows, manual operations create friction that limits quality and scale.

⚠️ Current Challenges

  • Paper admission forms, no pipeline visibility
  • Cash fee collection with no automated tracking
  • No parent portal — updates via WhatsApp only
  • No centralised gradebook or progress reports
  • No HR system — leave and appraisals handled informally
  • No finance reporting — no Ledger, Trial Balance, or P&L
  • Sick bay records in paper files, no inventory

✅ What This Platform Delivers

  • Online 8-step admissions form, 7-stage pipeline
  • WiPay Caribbean — TTD card payments, auto invoices & receipts
  • Parent portal — live grades, behaviour, report cards
  • Automated gradebook: CA 30% + Exam 70%, quizzes
  • Full HR: clock in/out, leave, CPD, performance reviews
  • Double-entry accounting: Ledger, P&L, Balance Sheet, payroll
  • Digital sick bay: patient records, medication inventory

Section 04

Technical Stack & Infrastructure

⚙️ Backend

  • FastAPI 0.115 (Python 3.12) — async REST API
  • MongoDB 7 — 144 collections, 62 API modules
  • ~54,000 lines of Python, role-based access control
  • Brute-force lockout, rate limiting, full audit trail
  • PDF generation, WebSocket chat, web push (VAPID)
  • OpenAI GPT-4 plagiarism + Google Gemini search

🖥️ Frontend & Server

  • React 19 + Tailwind CSS + Radix UI
  • ~32,200 lines of JSX across 95+ pages
  • PWA — offline support, install prompt, background sync
  • Namecheap Magnetar VPS — 6 cores, 8GB RAM, 240GB SSD
  • Nginx + PM2 + Let's Encrypt SSL + UFW firewall
  • Namecheap weekly snapshots + MongoDB cron backups

🌊 WiPay Caribbean — TTD-Native Payment Gateway

Purpose-built for Trinidad & Tobago. Supports TTD, USD, JMD, BBD natively. All transactions go through a Hosted Payment Page (PCI DSS compliant) with 3D Secure authentication. Server-side webhook verification — no payment data stored on the school's server. PDF invoices and receipts generated and emailed automatically on every payment.
