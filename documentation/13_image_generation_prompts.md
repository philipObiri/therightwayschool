## USAGE NOTES

### Recommended Tools
| Tool | Best For |
|------|----------|
| **Midjourney v6** | Highest photorealism, best skin tone accuracy |
| **DALL-E 3** (via ChatGPT) | Quick iterations, good diversity compliance |
| **Adobe Firefly** | Safe for commercial use, good at natural light |
| **Ideogram** | Strong text + image, good for signage shots |

### Tips for Best Results
- Add `--ar 16:9` (Midjourney) for website hero banners
- Add `--ar 4:5` for portrait/mobile cards
- Add `--ar 1:1` for gallery thumbnails and testimonial avatars
- Add `--style raw` in Midjourney for less AI-stylised, more documentary feel
- Append `photorealistic, Canon 5D, natural light, authentic expressions` to any prompt to push realism
- If skin tones are off, add `accurate diverse skin tones, no colour grading on skin`
